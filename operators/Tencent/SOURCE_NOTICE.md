# 来源与许可记录

本批 CE、RMSNorm、SiTU-GLU v2 代码来自仓库维护者提供的两份代码附件。
维护者明确要求将其按六个 kernel 入口发布在本仓库的 `Tencent` 目录。
这个目录名是维护者指定的分类名，不作为腾讯官方发布、认可或版权所有权的证明。

附件未提供公开上游 URL、Git revision 或许可证声明，以上字段如实记录为缺失；
不虚构原仓库或许可，也不把本仓库根 Apache-2.0 许可证自动套到这些外部 kernel。
后续如取得原始来源与许可，应补充本文件及元数据，并保留当前溯源记录。

每个算子的 `upstream/` 保存原附件中提取的 JIT 源码快照，按仓库约定规范为 LF 换行；这里只提取函数和依赖 helper，
未发布附件中的整套顶层测试或私有路径。`kernels.py` 继续保留原函数体、签名、装饰器与注释。
`case.py`、`launch.py` 和批跑整合是本仓库新增的测试代码。

[source-manifest.json](source-manifest.json) 记录原附件及提取快照 SHA-256，
各 `operator.json` 记录确切符号、快照路径、LF 快照哈希、规范化前哈希和验证状态。
原附件路径与使用者的机器信息不进入公开仓库。
